# プロジェクト概要（AgentGuard）

> 移行元: `.kiro/specs/agent-guard/requirements.md`（Kiro spec）。内容は原文のまま章単位で分割している。
> Requirement 番号は全要件を通した通し番号で、他ファイルの要件も「Requirement N」で参照する（1〜19・24・25 は機能要件、20〜23・26 は非機能要件）。

## 1. 概要


AgentGuard（リポジトリ名: `agent-guard`）は、AI コーディングエージェント（Kiro / Claude Code）の設定ファイルを静的解析し、過剰な権限・自動承認、シークレット露出、サプライチェーンリスク、危険なコマンド、プロンプトインジェクションを誘発する記述を検出して、日本語で「何が危ないか」と「どう直すか」を提示するツールである。

想定ユーザーは、AI エージェントを業務・個人開発で利用する開発者と、チームの PM / リードである。コミット前・CI・レビュー時に、エージェントに渡している権限や MCP 構成の「見えないリスク」に機械的に気づけるようにすることを価値とする。

MVP は Python 3.12 製の CLI を中核とし、日本語テキスト / JSON / SARIF の 3 形式でレポートを出力する。検出ルールはコードではなくデータ（YAML のルールパック）として定義し、追加・無効化・将来の他エージェント対応を可能にする。ツール自体の安全性として、スキャン対象を実行・評価せず、ファイルを変更せず、シークレットの原文を出力せず、オフラインで決定的に動作することを必須とする。
